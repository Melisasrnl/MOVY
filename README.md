# MOVY

Movy is is a social media-like app with the focus on films. Its an
app that is easy to use and gives people the opportunity to connect with others based on
mutual interest and respect. You can log the movies you watched,
rate, review and recommend movies, find contacts and chat with them or read about films and
latest news in the film industry; all without the need of another app.


### Execution Instructions:
In order to run the program properly, follow the steps below:

1. Make sure you have Java 11 (or higher), and Maven installed on your system.
2. Clone this repository to your local machine using the terminal:
   `git clone https://github.com/Melisasrnl/MOVY.git`
3. Open a terminal and navigate to the root directory of the project (where the `pom.xml` file is located).
4. Run the following Maven command to compile and execute the application:
   `mvn clean javafx:run`

*Note: This application requires an active internet connection to fetch real-time movie data from the TMDB API and connect to the cloud database.*

### About UI:
JavaFX is used for the interface. Also Scene Builder is used for home, about movie and comments pages.
